# Berkontribusi

Gunakan Python 3.10+ lalu jalankan `python -m unittest -v` dan `python examples/run_demo.py`. Tidak perlu memasang dependency. CI memeriksa Ubuntu dan Windows, Python 3.10/3.12/3.14.

Untuk bug, tulis versi Python/OS, perintah reproduksi, hasil yang diharapkan dan aktual. Gunakan topik serta waktu sintetis; jangan mengunggah database pribadi. Perubahan harus mempertahankan aturan minggu, transaksi, parameter SQL dan perlindungan overwrite. Sertakan tes untuk perilaku penting yang berubah, beserta dokumentasi dan changelog. Perubahan skema memerlukan desain migrasi eksplisit; jangan mengganti user_version tanpa kompatibilitas yang diuji.

Ajukan PR dengan masalah konkret dan bukti tes. Maintainer meninjau lingkup dan hasil sebelum menerima. Bantuan AI boleh digunakan, dengan penjelasan jujur atas bagian yang dibantu dan pemeriksaan hasilnya. Perilaku saling menghormati berlaku untuk semua diskusi.
