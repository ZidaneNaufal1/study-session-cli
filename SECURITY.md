# Keamanan

Versi yang dipelihara: 1.0.x. Program berjalan lokal tanpa jaringan. Gunakan database/folder tepercaya; validasi skema bukan isolasi database yang sengaja berbahaya. Data tidak dienkripsi. Jangan memasukkan password/token dalam topik atau laporan bug.

Untuk masalah tanpa data sensitif, buka issue dengan reproduksi sintetis. Jika membutuhkan pengungkapan privat, hubungi maintainer melalui metode kontak yang benar-benar tersedia pada profil GitHub terlebih dahulu untuk menyepakati jalur privat. Jangan membuka issue publik dengan rahasia; proyek belum menjanjikan kanal privat khusus atau SLA respons.
